KATOONz x TOMO Queue Manager v2.0

วิธีอัปโหลดขึ้น GitHub Pages
1. แตกไฟล์ ZIP
2. เข้า Repository ของ GitHub
3. กด Add file > Upload files
4. อัปโหลดไฟล์ทั้งหมดที่อยู่ในโฟลเดอร์นี้
5. ต้องเห็น index.html อยู่ระดับบนสุดของ Repository
6. ไปที่ Settings > Pages
7. Source: Deploy from a branch
8. Branch: main
9. Folder: /(root)
10. กด Save

วิธีติดตั้งบน iPad/iPhone
1. เปิดลิงก์ GitHub Pages ด้วย Safari
2. กด Share
3. Add to Home Screen
4. เปิด Open as Web App
5. กด Add

Android
1. เปิดด้วย Chrome
2. เมนู ⋮
3. Install app หรือ Add to Home screen
