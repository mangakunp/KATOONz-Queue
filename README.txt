KATOONz x TOMO Queue Manager v4.3 — Waiting Queue

แก้จากการใช้งานจริง

1. ระบบคิวตามเวลารอ
- เลือก 4 คนที่นั่งรอนานที่สุดก่อนเสมอ
- ไม่ใช้จำนวนเกมเป็นเกณฑ์
- คนที่มาช้าจะเริ่มต่อท้ายคิวตามเวลาที่เข้าร่วม
- คนที่เพิ่งจบเกมจะถูกส่งไปต่อท้ายคิว
- แสดงหมายเลขคิวของคนพัก

2. ลดผู้เล่นซ้ำรอบต่อรอบ
- ผู้เล่นที่เพิ่งจบจะไม่ถูกเลือกซ้ำทันที หากยังมีคนเก่ารอครบ 4 คน
- การเปลี่ยนตัวด้วยการแตะหรือลาก จะอัปเดตลำดับคิวด้วย

3. จัดคู่แบบหมุนเวียน
- เลือกผู้เล่นจากคิวก่อน แล้วค่อยจัดทีม
- เน้นลดคู่เดิมและคู่แข่งเดิม
- ให้ทุกคนทุก Level หมุนเวียนเจอกัน
- ลดน้ำหนักความสมดุล Level ลงมาก
- คู่ Level เท่ากันยังเกิดได้ แต่ระบบจะลดการจับซ้ำเกิน 1-2 ครั้ง

4. แก้อาการค้างตอนปรับ Level
- ใช้หน้าต่างปุ่ม Lv.1 / Lv.2 / Lv.3
- ไม่ใช้ prompt สำหรับ Level
- ปรับ Level สมาชิกโปรดแล้วอัปเดตผู้เล่นชื่อเดียวกันในวันนี้ด้วย

5. Firebase
- ซิงก์ queuePos และ queueCounter ระหว่าง PC / iPad / Android
- รองรับข้อมูลเก่าที่ไม่มีลำดับคิว โดยสร้างลำดับให้อัตโนมัติ

วิธีอัปเดต
1. แตก ZIP
2. ใส่ Firebase config จริงใน firebase-config.js
3. อัปโหลดไฟล์ทั้งหมดทับของเดิมบน GitHub
4. Commit changes
5. ปิด Web App ทุกเครื่องแล้วเปิดใหม่
6. เครื่องที่มีข้อมูลถูกต้อง กดส่งขึ้น Cloud 1 ครั้ง
