KATOONz x TOMO Queue Manager v3.0

ฟังก์ชันใหม่
1. Smart Queue
- เลือกคนที่จำนวนเกมน้อยก่อน
- จัดทีมให้ Level ใกล้เคียงกัน
- ลดการจับคู่เดิมซ้ำ
- ลดการเจอคู่แข่งเดิมซ้ำ

2. ประวัติรอบเล่น
- บันทึกเมื่อกดจบเกม
- แสดงคอร์ท เวลา และผู้เล่นทั้ง 4 คน
- เก็บสูงสุดที่แสดง 30 เกมล่าสุด
- ล้างประวัติได้

3. สำรองและกู้คืนข้อมูล
- ปุ่มสำรองข้อมูล ดาวน์โหลดเป็น JSON
- ปุ่มกู้คืนข้อมูล เลือกไฟล์ JSON ที่สำรองไว้
- สำรองผู้เล่น รายชื่อโปรด คอร์ท เกม และประวัติ

4. ฟังก์ชันเดิมยังอยู่ครบ
- รายชื่อโปรด
- เพิ่ม/ลบ/แก้ไขชื่อและ Level
- Drag & Drop
- แตะเพื่อเปลี่ยนตัว
- เพิ่มคอร์ทโดยไม่รีเซ็ตผู้เล่น
- เริ่มก๊วนใหม่โดยเก็บรายชื่อโปรด
- PWA และ Offline
