KATOONz x TOMO Queue Manager v2.2

ฟังก์ชันใหม่: ล้างข้อมูลทั้งหมดแบบหน้าว่าง

เมื่อกด “ล้างข้อมูลทั้งหมด” ระบบจะลบ:
- ผู้เล่นทั้งหมด
- จำนวนเกมทั้งหมด
- รายชื่อโปรดทั้งหมด
- จำนวนคอร์ท
- ชื่อ/หมายเลขคอร์ท
- ผู้เล่นที่กำลังอยู่ในคอร์ท

หลังรีเซ็ต:
- จำนวนผู้เล่น = 0
- จำนวนคอร์ท = 0
- รายชื่อโปรดว่าง
- สามารถเลือกจำนวนคอร์ทและเพิ่มผู้เล่นใหม่ได้จากศูนย์

วิธีอัปเดต GitHub Pages:
1. แตก ZIP
2. อัปโหลดไฟล์ทั้งหมดทับไฟล์เดิมใน Repository
3. Commit changes
4. รอ GitHub Pages อัปเดต
5. หากยังเห็นเวอร์ชันเก่า ให้ปิด Web App แล้วเปิดใหม่
