KATOONz x TOMO Queue Manager v5.2 — Smart Rotation OFFLINE

แนวคิดหลัก
- ไม่ใช้ AI ออนไลน์
- ไม่ใช้ Firebase
- ไม่ต้องมีอินเทอร์เน็ต
- ใช้อัลกอริทึม Smart Rotation ในเครื่อง

กติกาการเรียกผู้เล่น
1. เลือก 4 คนที่รอนานที่สุดก่อนเสมอ
2. คนที่เพิ่งจบเกมจะไปต่อท้ายคิว
3. คนมาช้าจะเข้าท้ายคิว ไม่ได้รับการชดเชยจำนวนเกม
4. ไม่ใช้ Level ในการเลือกผู้เล่น
5. ไม่พยายามทำให้จำนวนเกมทุกคนเท่ากัน

กติกาจัดคู่
- หลังได้ 4 คนแล้ว ระบบดูประวัติทั้งหมด
- ลดการเป็นคู่กับคนเดิม
- ลดการเจอคู่แข่งเดิมซ้ำ
- ประวัติ 8 เกมล่าสุดมีน้ำหนักสูงเป็นพิเศษ
- เป้าหมายคือให้ทุกคนค่อย ๆ ได้เป็นคู่และเจอกับคนหลากหลาย
- ถ้าผู้เล่นอยากเปลี่ยนคู่เองก่อนเริ่มเกม สามารถสลับได้ตามเดิม

สนาม
- ① เรียก
- ② เล่น
- ③ จบเกม
- ก่อนกดเล่น สามารถสลับผู้เล่นข้ามสนามที่อยู่สถานะ “เรียกแล้ว” ได้
- ระบบเก็บประวัติสนามที่แต่ละคนเคยเล่น เพื่อช่วยให้หมุนเวียนสนาม

Offline-first
- ข้อมูล Local Storage
- PWA Service Worker
- Backup / Restore JSON
- QR รับเงินเก็บในเครื่อง


ฟังก์ชันใหม่ v5.3
- บันทึกสถิติรายวันอัตโนมัติ
- เก็บจำนวนเกมทั้งหมดของวัน
- เก็บจำนวนเกมของผู้เล่นแต่ละคน
- เก็บจำนวนผู้เล่น สนาม ลูกแบด และค่าใช้จ่าย
- ดูย้อนหลังแบบรายวัน
- สรุปรวมแบบรายสัปดาห์ (จันทร์–อาทิตย์)
- Weekly Stats รวมจำนวนเกมของผู้เล่นแต่ละคน
- ข้อมูลประวัติอยู่ใน Local Storage และรวมอยู่ในไฟล์ Backup JSON
- ไม่มี Firebase / Cloud / Internet dependency

ก่อนใช้จริง
1. ทดสอบผ่าน Live Server
2. ลอง เรียก → เล่น → จบเกม อย่างน้อย 2-3 รอบ
3. เปิดหน้า สรุปค่าใช้จ่าย → ประวัติการเล่น
4. กด เริ่มวันใหม่ แล้วตรวจว่าประวัติวันเดิมยังอยู่
5. กด Backup JSON ก่อนนำไปใช้งานจริง
